Case Study: MySongHeadache

CONCEPT TO PRODUCTION

Building a Live Music Archival App with OpenAI GPT

MySongHeadache is a dedicated personal digital archive designed to capture "earworms"—songs that won't leave your head. Built with a distinctive '70s Op Art visual aesthetic, curving interlocking color paths, and seamless YouTube integrations.

By leveraging OpenAI's ChatGPT Canvas mode, the entire product lifecycle—from drafting the Product Requirement Document (PRD) to iterative prompt-driven component generation—was executed in record time.

SupabaseYouTube API v3Vanilla CSS 70s Op Art
PHASE 01 — ARCHITECTURAL PRD

AI-Driven Specification

Drafted a comprehensive PRD using GPT-5.6 , specifying App Router architecture, and structured YouTube Data API hooks.

PHASE 02 — ITERATIVE CO-CODING

Prompt-Driven Development

Refined complex CSS clip-path curves and background geometric loops iteratively through targeted natural language agent instructions.

PHASE 03 — PRODUCTION DEPLOYMENT

Interactive Live Web App

Deploys a fully functional admin suite and public mixtape player with password protection, YouTube search, and real-time playback.

Phase 01: PRD Architecture & Prompting

HUMAN + AI COLLABORATION

Precision Prompting with ChatGPT Canvas

Instead of manual boilerplate setup, the project originated by feeding a structured prompt into OpenAI's GPT Canvas workspace to generate a single-source-of-truth PRD (Version 2.0).

  • Defined strict tech stack parameters: Next.js App Router, Supabase DB, Vanilla CSS Modules.
  • Specified 1970s Optical Art graphic design rules with SVG paths and clipping curves.
  • Created clear User Stories for search, embed, password verification, and timeless feed ordering.
